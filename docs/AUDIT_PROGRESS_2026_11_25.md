# Audit TravelBudget : travail séparé de F13

- **F2, file hors ligne** : un ancien résultat ne déclenche plus de notification si une révision plus récente n’a pas été confirmée. Une action Sport ou Nutrition reste en file si son module ne peut pas être chargé. Le rejeu contrôle de nouveau le compte et le verrou après le chargement différé. Trip recharge son module à la reprise même si l’onglet n’a pas été ouvert. Une action remplacée ou appartenant à l’ancien compte n’est pas envoyée après le chargement ; une nouvelle prise de verrou ne peut pas retenir une ancienne tentative devenue orpheline. Les onglets du même compte voient les changements de file sans déclencher un envoi supplémentaire. Les écritures génériques dans localStorage ne sont pas encore transactionnelles entre tous les onglets.
- **F4, sommeil** : la saisie et la suppression sont enregistrées avant l’appel réseau. Une suppression hors ligne reste masquée jusqu’à confirmation et ne réapparaît pas au retour d’une lecture plus vieille. Le rejeu vérifie le compte et la révision, et garde la saisie locale si la nuit a changé sur un autre appareil. Les onglets compatibles utilisent Web Locks pour écrire et synchroniser ; sur les autres, seule la sérialisation dans une même page est garantie. Le module d’écriture est chargé à la demande ; le plafond JS initial reste à 279 Kio, les plafonds différé et total passent respectivement à 605 et 884 Kio. La résolution interactive des conflits et la transactionnalité complète des repas restent ouvertes.
- **F11, base** : la revue des droits est actualisée et une migration gardée est prête pour retirer deux index identiques de Transactions en conservant l’index utilisé. La migration n’a pas été appliquée et aucun gain de temps de requête ne peut être déduit de la seule économie de stockage. Voir le complément de l’audit SQL.
- **Analyse** : sept graphiques ont été cartographiés, deux calculs corrigés. Le comparatif pays impute dépenses et remboursements aux jours effectivement couverts ; la heatmap affiche les mêmes montants journaliers que la cadence, y compris en mode prévisionnel. Voir le détail et les vérifications visuelles restantes dans `ANALYSE_GRAPH_AUDIT_2026_11_25.md`.

Aucune modification de F13, de la production ou du Play Store.
